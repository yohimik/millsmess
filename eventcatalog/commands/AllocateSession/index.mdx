Start a runtime under a reserved owner lease.

## Responsibility

Producer: **Core**. Consumer: **MediaEngine**. Delivery: **durable**. Channel: **EngineCommands**.

## Preconditions and effects

Core reserves capacity and owner epoch in a regional transaction. Only targeted engine incarnation may consume; engine verifies current lease and READY state before boot. Same allocation ID is idempotent; late allocations to DRAINING reject. The mandatory session-recording index and durable capture path must exist before runtime launch; configured audio/video capture starts before admitting corresponding tracks.

## Ordering and idempotency

Tenant + region + cluster + aggregate ID. Broker partition order is scoped to one aggregate; aggregateRevision is assigned by that aggregate owner, never by the client.

Deduplicate by tenantId + producer authority + messageId; retain aggregate transitions and terminal settlement uniqueness beyond broker retention.

## Failure handling

Retry transient failures with jitter. Commit inbox deduplication and state/outbox together before ACK. Quarantine invalid/unsupported messages in a bounded DLQ with reason and alert; retain original identity on replay. Stale ownership is rejected, not retried blindly.

Success/reply contract: **SessionStarted**. A rejected request uses **CommandResult** with a stable error code.
