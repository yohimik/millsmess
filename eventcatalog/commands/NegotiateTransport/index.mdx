## Responsibility

Producer: **Socket, client**. Consumer: **MediaEngine**. Delivery: **ephemeral**. Channel: **MediaSignaling**.

## Preconditions and effects

Validate admission ticket before allocating expensive resources. SDP is used only for WebRTC; WebSocket/UDP omit it. Negotiate DTLS/SRTP or secure datagram adapter before payloads. Reject unsupported capability; never silently downgrade reliability.

## Ordering and idempotency

Authenticated request or connection + message type + caller. The trusted receiver derives identity from credentials and rejects tenant/region/cluster mismatches.

See the domain delivery contract for replay windows, payload-hash conflicts and admission expiry.

## Failure handling

Reject invalid, unauthorized, expired or unsupported requests with CommandResult. Use the same idempotency key after a lost response; transient retries use bounded exponential backoff and jitter. Credentials, SDP and tickets are never durable-broker messages.

Success/reply contract: **TransportNegotiated**. A rejected request uses **CommandResult** with a stable error code.
