Admit a late-joining player or spectator into an open session.

## Responsibility

Producer: **Socket, client**. Consumer: **Core**. Delivery: **request-response**. Channel: **ControlAPI**.

## Preconditions and effects

Check ACL, game join policy, capacity, current ACTIVE owner and negotiated capabilities. Reserve membership transactionally; issue short-lived owner-bound ticket. DRAINING engines allow joins to existing sessions only if the original endsBy cannot extend.
